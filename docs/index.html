pour — AI Skill Manager

Why pour

Everything you need

A simple, fast, open-source CLI built for the way you work

🔌

Any GitHub Repo

Point pour at any public GitHub repo. It scans for SKILL.md files automatically — no fixed structure required.

⚡

Instant Install

Skills are copied directly to the right folder for your AI agent. No config, no setup. Just works.

🤖

Multi-Agent

Supports Claude, Cursor, Windsurf, Copilot, and more. Use the -a flag to target any agent.

🎨

Interactive UI

When a repo has multiple skills, pour shows a beautiful interactive picker so you can choose exactly what to install.

🌍

No Registry

GitHub is the registry. Anyone can host skills in their own repo. No central server to maintain or trust.

🔓

No Auth Required

Works out of the box with public repos — no signup, no token needed. Optionally add a GitHub token for higher rate limits.

Commands

pour add
Install skills from any GitHub repo
pour add acme/ai-skills -a claude copy
pour search
Discover skill repos by keyword
pour search code review copy
pour list
See all installed skills grouped by agent
pour list -a claude copy
pour update
Update all installed skills to latest version
pour update copy
pour remove
Uninstall a skill from an agent
pour remove ui-design -a claude copy
pour init
Create a new SKILL.md template to share
pour init my-skill copy
pour auth login
Add a GitHub token for higher API limits
pour auth login copy
pour add ... -g
Install a skill globally across all projects
pour add owner/repo -a claude -g copy
